# Professional Portfolio Website

A responsive, multi-page developer portfolio built with semantic HTML5, CSS3 and vanilla JavaScript for the WeIntern Week 1 assignment.

## Pages
- `index.html` — Home / hero / selected projects
- `about.html` — Profile, approach and skills
- `projects.html` — Project cards and category filtering
- `contact.html` — Contact details and validated contact form demo

## Technology
- HTML5 semantic elements
- CSS3, Flexbox, CSS Grid and media queries
- Vanilla JavaScript
- Local browser storage for theme preference

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser, or use VS Code with the Live Server extension.
3. Navigate between Home, About, Projects and Contact.

No package installation or build step is required.

## Before publishing
- Verify every personal detail and project description.
- Replace `replace-with-your-email@example.com` in `contact.html` and `js/script.js` with the public email address you want to use.
- Add real GitHub repository and live-demo links to each project.
- Add a real resume file if you decide to offer a resume download.
- Capture the required desktop and mobile screenshots in `screenshots/`.

## Contact form limitation
The form uses built-in browser validation and can prepare a message in the visitor's default email app after you configure the recipient address. It does not send or store messages on a server.

## Deployment
This is a static website and can be hosted on GitHub Pages, Netlify or Vercel. For GitHub Pages, configure the repository's Pages settings to publish from the branch and folder where this project is stored.
